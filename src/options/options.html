Workspaces

One workspace per client or brand. Each has its own approved values, naming rules, domains, presets, shortener and webhook.

🔒 Rules for this workspace are locked by an admin.

Naming rules

Required fields

Approved values

One per line. Add a display name with value = Name, e.g. facebook = Meta – Facebook. The value goes in the URL; the name is what people see.

    Campaign name formula

    Leave empty for free text. [field] is an input, [field|a,b,c] a dropdown, [date:yyyy-mm] today's date (tokens yyyy yy mm dd ww q). Variables: [page_title] [domain] [path] [client] [user]. Variables also work in any field in the builder.

    Default custom parameters

    Added to every link in this workspace, e.g. ref=partner. One key=value per line.

    Presets

    Save presets from the Build tab. Give them a folder to group them in the preset menu.

      Import presets from another tool

      CSV or JSON exported from another UTM builder or a spreadsheet. Columns or keys like name, folder, source, medium, campaign, content, term are recognised. Every value is cleaned with this workspace's naming rules.

      Approval requests

      When a list is locked, teammates can request a new value from the builder. Paste their request here to review and approve it.

      Link shortener (bring your own key)

      Your key is stored only in this browser and sent only to the provider. Custom endings and click counts use the provider's API; Bitly custom endings need a paid Bitly plan.

      QR codes

      Defaults for this workspace. You can still change colours and caption per code in the builder.

      Webhook & Google Sheets Pro

      Every link you copy or shorten in this workspace is sent here. Works with Zapier, Make, Slack incoming webhooks, or a Google Sheet via Apps Script.

      1. Open your tracking sheet → Extensions → Apps Script.
      2. Replace the code with the script below and save.
      3. Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone. Copy the web app URL.
      4. Paste it above, choose “Google Sheets”, click Allow, then Send test.

      Adobe Analytics

      The code joins source, medium, campaign, content and term, e.g. cid=facebook:paid_social:winter-boots.

      Admin lock Pro

      Set a PIN to lock this workspace's rules, approved values, formula and presets. Teammates who import it can build links but can't change the rules. This prevents accidental changes; it is not a security control.
